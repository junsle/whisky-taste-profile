# whisky-taste-profile

개인 위스키 취향 프로파일. 단일 HTML 파일로 되어 있고 외부 의존성이 없다.

- 사이트: https://junsle.github.io/whisky-taste-profile/
- 소스: `index.html` (CSS · JS · 파비콘 모두 인라인)

## 갱신 방법

1. Claude가 이 폴더의 `index.html`을 새 버전으로 덮어쓰고 커밋을 만든다
2. Fork에서 Push
3. 약 1분 뒤 GitHub Pages에 반영

## 문서 구성

| # | 섹션 |
|---|---|
| 01 | 네 개의 평가 축 — 통합도 · 밀도 · 전개와 연결감 · 피니시의 질 |
| 02 | 이상적인 흐름 |
| 03 | 기억점의 조건 |
| 04–05 | 점수 체계 · 점수 기록 |
| 06–07 | 감점 트리거 · 향미 팔레트 |
| 08–09 | 카테고리별 취향 · 평가 방식과 신뢰 조건 |
| 10–11 | 구매 결정 규칙 · 추천 규칙과 제시 형식 |
| 12–14 | 적합/부적합 신호 · 셀러 현황 · 갭 분석 |
| 15–17 | 셀러 운영 계획 · 추천 제외 목록 · 남은 빈칸 |
